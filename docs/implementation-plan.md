# 萌宠小镇数学冒险：实施计划

更新日期：2026-07-27

## 1. 产品基线

- 目标用户：上海小学一年级儿童，包含尚不能独立阅读的孩子。
- 首期学科：数学。
- 教材范围：上海教育出版社五四学制一年级上册；当前仅依据公开单元结构规划，精确知识点必须经过目录或教材内页复核。
- 首期知识域：`10以内的数`。
- 游戏主题：萌宠小镇冒险。
- 首发平台：Web、Android APK；微信小游戏作为首版稳定后的独立可行性验证。
- 引擎：Godot 4.7，2D，1280×720 横屏。
- 核心成功标准：孩子无需识字也能理解操作，并愿意主动重玩。

## 2. 产品原则

1. 一次只给一个行动指令，语音可随时重播，并配合视觉高亮。
2. 答错不扣分、不掉生命，不播放羞辱或惊吓反馈；只提供更短的提示。
3. 教学内容由 Codex 直接设计和维护，不在游戏运行时接入任何大模型 API。
4. MiniMax 仅在开发阶段离线生成 TTS；API Key 不进入 Git、Web 或 APK。
5. Bitto 用于原创角色与场景美术；可计数物件使用独立精灵组合，不用 AI 生成固定数量的物件组。
6. 不复制教材扫描页、题目原文或教材插画。

## 4. 技术结构

- `ContentRepository`：加载并校验课程 JSON。
- `CountQuestionGenerator`：生成可复现的数量题目序列。
- `ProgressStore`：保存匿名本地进度。
- `AudioManager`：播放预生成语音和音效，缺少素材时安全降级。
- `SceneRouter`：管理场景切换。
- `content/`：教材对齐状态、题目参数和提示语。
- `audio/tts/`：预生成语音与非敏感音频注册表。

## 5. 当前风险与处理

| 风险 | 处理方式 |
| --- | --- |
| 只有教材封面，无法核对具体页面 | 先做公开单元范围内的基础数概念，设置教材校验门 |
| 幼儿不识字 | 语音优先、图形操作、重播按钮、短指令 |
| Godot 微信小游戏支持不如 Web/APK 直接 | 首版后单独做技术验证，不阻塞首个可玩版本 |
| API Key 曾出现在聊天 | 不写入项目；生成语音前必须轮换 |
| AI 美术出现计数错误 | 单个物件独立生成与组合，数量由游戏逻辑控制 |
